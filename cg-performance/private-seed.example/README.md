# private-seed (exemplo)

Copie esta pasta para `private-seed/` (que é ignorada pelo git) e substitua pelos seus dados reais:

- `profile.json` — perfil, objetivos e relatos de treinos já executados (`personalLog`).
- `*.csv` com `composicao` no nome — histórico de composição corporal (mesmo cabeçalho da planilha).
- `equipamentos/*.jpg` — fotos do home gym (aparecem na tela Equipamentos).
- `treinos_box/*.jpg` — prints de WOD do box: entram na fila de importação para OCR + revisão.

Os arquivos só são lidos na **primeira abertura** do app (ou depois de "Apagar todos os dados").
Valores aqui são fictícios.
