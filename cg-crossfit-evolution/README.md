# CG CrossFit Evolution (artefato)

Versão simplificada, em um único arquivo, publicada como artefato do Claude:
https://claude.ai/artifact/9ycDAbCkawQJUZ6Jvm9F8m (privado).

- **Hoje**: mapa do corpo dos últimos 14 dias (core, superiores, pernas, fôlego), sugestão de foco e briefing (onde, tempo, foco, como está).
- **Treino**: aquecimento, bloco principal com cronômetro (AMRAP, EMOM ou intervalos) e animação grande de cada exercício, trocar exercício, registrar esforço.
- **Histórico**: adicionar treino do box por foto (o Claude lê o print) ou digitando; os nomes reconhecidos alimentam o mapa.

Dados: banco do artefato (coleção `treinos`, leitura e escrita só do dono). Sem banco disponível, o app guarda no navegador.
Para alterar, edite `index.html` e republique no mesmo link.
